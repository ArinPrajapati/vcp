How to use multiple Vercel accounts on one computer

The Vercel CLI remembers one login. Here are three ways to work with more than one account, from a manual setup to a one-command tool, and when each one makes sense.

Why the CLI only handles one account

When you run vercel login, the CLI saves your token in a global config folder. On macOS that is ~/Library/Application Support/com.vercel.cli. Every command reads that same folder, so it can only ever act as one user.

The CLI does have a flag that points it at a different folder: --global-config (short form -Q). All three methods below rely on that idea or on tokens.

Method 1: separate config folders by hand

Give each account its own folder and pass it on every command.

vercel --global-config ~/.vercel-work login
vercel --global-config ~/.vercel-work whoami

# shorter, in your shell rc file
alias vcw='vercel --global-config ~/.vercel-work'

This works and needs nothing installed. The catch is that you have to remember which command to use in which repo. Run plain vercel in the wrong place and you are using the wrong account.

Method 2: a token per account

Create an access token for each account in the Vercel dashboard, then pass it with VERCEL_TOKEN or --token.

VERCEL_TOKEN=<work-token> vercel deploy

This is the right choice for CI, where there is no browser. On a laptop it means creating, storing and rotating a token for every account, and you still choose the token by hand each time.

Method 3: vcp, which picks the account per repo

vcp automates Method 1. Each account becomes a profile, and the right one is chosen from the folder you are in.

curl -fsSL https://raw.githubusercontent.com/ArinPrajapati/vcp/main/install.sh | sh

vcp import personal   # adopt your current login
vcp add work          # log in a second account

cd ~/client-site
vcp pin work          # this repo now uses "work"
vercel whoami         # runs as the work account

Outside that repo, vercel uses your default profile. You can add as many profiles as you need, and two terminals can use two different accounts at the same time.

Which method should you use?

SituationBest fit
Two accounts on a laptop, many reposvcp
One-off use, nothing to installMethod 1, separate folders
CI or scripts without a browserMethod 2, tokens
One login, several teamsvercel switch, no extra tool

A gotcha: projects belong to an account

The .vercel/project.json file that vercel link creates refers to a project owned by one account. Open that repo under a different login and you will get a "project not found" or scope error. Always run a repo under the account that owns it, which is exactly what pinning a profile does.
